## 一、 零基础准备与编辑器启动

1. **环境要求**：本地安装了 Node.js 22 或更高版本（或使用 Forge 安装包中自带的 `node/node.exe`）。
2. **启动工坊编辑器**：
   - Windows 创作者直接双击根目录下的：`启动工坊编辑器.bat`（或在终端运行 `npm run editor`）。
   - 控制台出现 `Forge Editor running at http://127.0.0.1:3001`。
3. **打开浏览器**：访问 `http://localhost:3001`，即可进入包含 9 大专属工作台的可视化界面。

## 二、 新建你的第一个模组

每个模组是一个独立的包（Pack），避免和游戏官方文件冲突：

1. 打开编辑器顶部菜单的 **「模组信息与打包」**（`/pack.html`）；
2. 点击 **「新建模组」**，输入你的包英文唯一 ID（如 `my-first-pack`）；
3. 填写基本信息：
   - **名称**：我的第一个同人扩展包
   - **版本**：1.0.0
   - **作者**：你的昵称
   - **开源协议**：GPL-3.0-or-later 或 CC-BY-NC-4.0（非商用）
   - **简介**：新增 1 名干员、2 件自制装备与 1 个阵营盟约。
4. 点击「保存」，本地 `workshop/my-first-pack/` 目录自动创建就绪。

## 三、 实战 1：捏一名原创干员

进入首页（`http://localhost:3001/`）：

1. **基础设定**：
   - **干员 ID**：如 `char_ws_my_ranger`（自动带 `char_ws_` 前缀，防止与官方重名）。
   - **干员名称**：巡林守卫
   - **星级**：5 星（Tier 5）
   - **职业与分支**：狙击（SNIPER） -> 快狙（fastshot）
   - **站位与阻挡**：高台远程（RANGED），阻挡数 1。
2. **面板数值（两套）**：
   - 编辑器左右两列：左边填「普通形态（精一）」，右边填「精锐形态（精二）」。
   - 如生命 1600 / 2100，攻击 520 / 680，防御 130 / 170，费用 12。
3. **攻击范围绘制**：
   - 可以在下拉框中选择官方现成的 184 种攻击范围模板；
   - 也可以点击「网格画板」自由点击方格涂抹攻击范围。
4. **技能黑板树配置**：
   - 技能名称：「穿甲风暴」；
   - 触发方式：手动触发（MANUAL），弹药制（AMMO，8 发）；
   - 黑板参数：在黑板表中添加 `atk: 0.6`（攻击力+60%）、`attack_speed: 30`（攻速+30）。
5. **模型与立绘绑定**：
   - 在模型下拉框直接选择官方干员的 Spine 模型（如白铁、能天使、克洛丝等），右侧 3D 视口实时显示待机动作。

## 四、 实战 2：制作自定义装备与上传图片

进入 **「装备制作」**（`http://localhost:3001/item.html`）：

1. **自备原创图片（推荐）**：
   - 画一张 128×128 或 256×256 的透明底 PNG 图片，命名为 `storm_bow.png`；
   - 放入当前模组目录下的 `workshop/my-first-pack/assets/item/storm_bow.png`；
   - 刷新装备页面，在「自选本地图标」下拉框中直接就能看到并选中 `storm_bow.png`！
2. **借用官方图标（免画图）**：
   - 如果不想画图，直接在「图标 trapId」下拉框里搜索并挑选官方现成的几百种精美装置图标（如 `trap_1013_lhp`）。
3. **设定装备词条（Buffs）**：
   - 装备名称：「疾风长弓」；
   - 售价：3 战术点（Tier 2）；
   - 词条 1：`atk_ratio: 0.2`（攻击力提升 20%）；
   - 词条 2：`attack_speed: 15`（攻速+15）；
   - 偏好盟约：可选择赋予羁绊标签（如关联「巡林者」盟约）。

## 五、 实战 3：搭建原创阵营盟约

进入 **「盟约制作」**（`http://localhost:3001/bond.html`）：

1. **盟约基本信息**：
   - ID：`bondeffect_forest`，名称：「林地隐修会」；
   - 上传盟约徽记图标（PNG 放入 `assets/bond/forest.png`）。
2. **梯级羁绊阈值**：
   - 2 人羁绊：全队林地干员获得 15% 物理闪避；
   - 4 人羁绊：闪避成功时对攻击者反弹 200 点法术伤害；
   - 6 人羁绊：入场时召唤一头林地雪豹协同作战。
3. **分配干员名单**：
   - 勾选哪些官方干员与自制干员属于该盟约。

## 六、 实战 4：手绘一张战场地图与出怪波次

进入 **「地图制作」**（`/stage.html`）与 **「波次制作」**（`/wave.html`）：

1. **地图尺寸**：选择标准 19×21 棋盘；
2. **刷地形**：点击画笔，用鼠标左键拖拽绘制高台（可部署远程）、地面（可部署近战）、不可通过深坑；
3. **放红门与蓝门**：标定敌方生成点 `S` 与防守目标点 `E`；
4. **内置寻路计算**：点击「测试寻路」，编辑器内置 A* 引擎会自动推算出敌兵的行进路径；
5. **排布波次**：在 `/wave.html` 中设置第 1 回合第 3 秒刷 2 只猎狗，第 15 秒刷 1 名精英术师。

## 七、 进阶实战：编写行为层 Kit 技能代码

如果你想做出官方没有的奇特机制（如：偷取敌人物防、阵亡全图自爆、击杀刷新技能）：

1. 进入 **「Kit 代码工作台」**（`/kit.html`）；
2. 选中干员 `char_ws_my_ranger`，内置代码编辑器会生成基础骨架：
   ```js
   export default function kit(bb, chess, def) {
     return {
       skill: {
         kind: 'manual',
         sp: 30,
         // 挂接技能释放钩子
         onCast(battle, unit) {
           battle.log(`${unit.name} 释放了疾风箭雨！`);
         }
       },
       talents: [{
         name: '弱点洞悉',
         // 挂接攻击命中钩子：每次攻击偷取目标 10 点防御
         onHit(battle, attacker, target, damage) {
           target.def = Math.max(0, target.def - 10);
           attacker.atk += 10;
         }
       }]
     };
   }
   ```
3. 点击「静态检查」，编辑器会自动对 36 个事件钩子进行无死循环、无非法越权的安全核查。

## 八、 一键打包与游戏内导入实测

1. **打包导出**：
   - 进入 `/pack.html`，点击 **「导出模组包」**；
   - 系统自动生成 `my-first-pack-1.0.0.zip`。
2. **手机端与电脑端导入**：
   - 启动游戏（PC 网页端或 Android 手机版）；
   - 在游戏主页点击 **「模组」** 管理器；
   - 点击 **「选择本地模组包 (.zip)」**，选中刚才导出的 zip；
   - 流式解析器瞬间解析出干员特质、README 与装备列表，自动存入客户端 IndexedDB 离线沙盒；
   - 开一局单人或联机房间，你的新干员、新装备和新地图全部生效！
