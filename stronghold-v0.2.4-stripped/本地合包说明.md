# 本地纯净版：v0.2.4（已剥离无限火力）

完成日期：2026-10-11。实际代码基线为官方 v0.2.4（commit bc50cac01ff447eff3ab6c35f69d934bbc23b48f）。

## 说明

- 本包已完整剥离“无限火力”（Firepower / RandomMode）相关模块与玩法逻辑。
- 完整保留了当前服务器的皮肤系统、准备阶段换肤即时生效补丁、私密房间、联邦大厅、多服选择、身份恢复、聊天弹幕、语音支持、横屏适配、本地资源准入与网络优化。
- 大厅回归标准模式（单人独立模拟 / 多人同盟模拟）。
- 所有单测、静态资源校验与准备阶段皮肤回归测试全部通过。

## 使用

1. 安装 Node.js 22 或 24 LTS。
2. 双击“启动本地游戏.cmd”，浏览器会打开 http://127.0.0.1:3000/。
3. 导入桌面完整资源包（.spresources 文件，版本 f3216bd82a48，13,889 个文件）。
4. 创建独立模拟或同盟模拟房间即可开始游戏。
