## 3. 变换参数（可复现；Pillow 12.3.0 + numpy）

全部在 **96×160 的基底**上做颜色分级，再预乘缩放上 128×160 画布。要点：

### 3.1 颜色分级（float 0–1，HSV 手算避免 8-bit 量化）

```python
v2 = clip((v ** 0.96) * 1.00, 0, 1); v2 = clip(0.5 + (v2 - 0.5) * 1.28, 0, 1)   # CONTRAST 1.28
v2 = v2 - 0.70 * smoothstep(v2, 0.78, 1.0) * (v2 - 0.78)                       # TOP_K：压顶部，防折面全顶白
v2 = clip(v2 + (v - blur(v, 1.0)) * 1.90, 0, 1)                                # DETAIL_K：把基底 v 细节放回去

crystal_w = smoothstep(s, 0.20, 0.42)          # 饱和度双峰分层
th        = 反复 MinFilter(3) 腐蚀 5 次 / 5    # 粗糙距离场
pearl_w   = (1 - crystal_w) * clip(0.55 + 0.45 * smoothstep(th, 0.28, 0.62), 0, 1)

# 晶体：玫瑰(亮) → 洋红(暗)
t_hue = clip((1 - ss(v,.30,1)) + (1 - (1 - ss(v,.30,1))) * (ss(s,.30,.80)*.85), 0, 1)
hue   = 0.947 + (0.888 - 0.947) * t_hue + (h - 0.5) * 0.06
s_c   = clip(s * 1.25 + 0.08 * (1 - s) ** 1.5, 0, 1)
cry   = hsv_to_rgb(hue % 1, s_c, v2)

# 珍珠：奶粉珠光色阶（按 v2 查表）＋浮雕
vp    = clip(v2 * 0.98 + 0.03, 0, 1)
pearl = interp(vp, [0,.25,.5,.72,.88,1],
               [(86,30,56),(150,74,104),(206,132,164),(236,180,206),(250,222,238),(255,247,252)])
pearl = clip(pearl * (0.52 + 0.62 * v2), 0, 1)

out = cry * (1 - pearl_w) + pearl * pearl_w
out *= 1 + ((1.06, 0.84, 0.92) - 1) * ((1 - s) ** 1.5 * 0.90)      # 暖乘法（只低饱和处）
out += (160, 62, 100)/255 * ((1 - v2) ** 1.5 * 0.16)                # 暗部酒红环境光
out  = mix(out, (255,209,232)/255, ss(v,.88,1)**1.3 * 0.22 * (1 - 0.90*s))   # 粉白高光 #FFD1E8
out  = mix(out, (255,60,168)/255,  ss(s,.35,.85) * ss(v,.62,1) * 0.18)       # 洋红晶面高光
out  = 1 - (1 - out) * (1 - blur(bright, 2.2) * 0.08)                        # 极淡柔焦晕
```

### 3.2 画布与光效（128×160）

1. **预乘缩放**：`rgb×α` → 等比缩到高 140（LANCZOS）→ 除以缩放后 α（反预乘）→ 居中（x=22, y=10）。
   直接对直通 alpha 缩放会在描边外留白/黑边，这一步是关键。
2. **内阴影**（先画）：`solid − MinFilter(11)` → blur 2.8 → 朝右下加权，色 `#3A0A24`、α 0.40。
3. **内发光**：`solid − MinFilter(5)` → blur 2.6 → 朝左上加权（最低 30%）× **厚度权重**（细晶簇≈0）× α 0.62，色 `#FFD1E8`。
4. **中心提亮**：以珠体中心为心的高斯（σ≈(0.85W, 0.62H)），屏混合 `#FFB2DA`、α 0.16。
5. **柔光斑**：(61,108) σ=(26,22)，`#FFD6EC`、α 0.14（低频，且乘 alpha，不会糊轮廓）。
6. **渐变环**：`MaxFilter(7) − solid`（外扩 3 px）+ blur 0.6；`t = (y/159)·0.85 + (x/127)·0.15`，`#FFA3CE → #C4005C`。
7. **外晕**：`blur(MaxFilter(7), 3.2) − solid`，`#FFA3CE`、α 0.20。
8. **心形角标**：8× 超采样画心形（`x=16sin³t, y=−(13cos t−5cos2t−2cos3t−cos4t)`），深底 `(42,7,22,232)`、
   粉描边 2.0 px、左内缘 1 px mint 细线（α 0.75）、`SP` 6.4 px `(255,236,246)`；**按 8×8 预乘盒平均下采样**，α<2/255 置 0。
9. **去白边**：α<0.25 的区域把颜色乘向环底色，杜绝淡淡的白边。

**生成后实测的不变量**：

- 尺寸 128×160 RGBA（`getbands() == ('R','G','B','A')`）；
- alpha>0 的 bbox = x[20,121] y[7,152]，**四边都不贴画布**；完全透明的像素 10,704 个；
- α<48/255 的区域里，**亮到 min-channel>0.80 的像素 0 个**（连 >0.62 的淡粉都为 0）——无白边；
- 轮廓、折面、明暗全部来自基底像素，只做颜色/明度重映射 + 光效层，没有新画一笔。

| 目标 | 参数 | 现 → 建议 |

> 色相整体再暖/再冷只动 `HUE_WARM`（亮部 0.947）与 `HUE_DEEP`（暗部 0.888）两个数；

> 会让晶面全部 clip，折面会糊成一片（本单就是靠 `SAT_GAIN 1.25` + 顶部压缩 `TOP_K 0.70` + `DETAIL_K 1.90` 把折面救回来的）。
